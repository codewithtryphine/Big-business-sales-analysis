# Small Business Sales Analysis

This project analyzes weekly sales data using Python.

- Dictionaries
- Loops
- Aggregation

- Revenue calculations

Outputs:
- Total revenue
- Product units sold
- Product revenue
- Daily revenue
- Best selling product
- Highest revenue product
- Best revenue day
